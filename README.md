# 揪汪汪家点餐工作台

家庭内部使用的可爱风点餐小工具：全家人登录后一起发布买到的食材，再把食材拖进「揪汪汪早餐/晚餐」「大人早餐/晚餐」四个框里，决定每天吃什么。

## 本地运行

```bash
npm install
npm start
```

打开 http://localhost:3000 即可。需要 Node.js 22.5 及以上版本（用到了内置的 node:sqlite）。

## 部署到 Render（免费）

1. 把这个文件夹上传到一个新的 GitHub 仓库（可以直接在 github.com 网页上新建仓库并拖拽上传文件）。
2. 打开 https://render.com ，用 GitHub 账号登录。
3. New + -> Web Service，选择刚才的仓库，Render 会自动读取 `render.yaml` 里的配置。
4. 一路默认下一步，几分钟后会得到一个形如 `https://xxx.onrender.com` 的公网地址，分享给家人即可。

免费套餐特点：连续 15 分钟没人访问会休眠，下次打开时需要等待约 30 秒唤醒；数据保存在服务自带的磁盘上，重新部署代码不会清空数据，但如果重建服务实例可能会丢失（家庭使用场景一般没问题）。

## 账号

首次使用时，每个家庭成员点"注册新账号"，自己设置用户名、昵称和密码即可，无需管理员创建。
